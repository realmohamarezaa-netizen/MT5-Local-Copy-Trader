# راهنمای نصب و راه‌اندازی (فارسی)

## ۱) پیش‌نیازها

- ویندوز ۱۰ یا ۱۱ نسخه **۶۴ بیتی**
- چند ترمینال **MetaTrader 5** نصب‌شده (هر کدام متصل به حساب بروکر — برای تست حتماً **حساب دمو**)
- فایل نصب برنامه: `TradingCopierSetup_x64.zip` از بخش Releases مخزن

## ۲) نصب برنامه

1. فایل ZIP را دانلود و باز کنید.
2. `TradingCopierSetup_x64.exe` را اجرا کنید.
3. مسیر نصب پیش‌فرض: `%LOCALAPPDATA%\Programs\TradingCopier`
   (نیازی به دسترسی Administrator نیست).
4. تیک **Create Desktop Icon** را بزنید و Install را کامل کنید.
5. اگر می‌خواهید برنامه با روشن شدن ویندوز اجرا شود، تیک
   **Run at Windows startup** را فعال کنید.

اطلاعات برنامه (دیتابیس، لاگ‌ها، تنظیمات) در مسیر
`%LOCALAPPDATA%\TradingCopier` نگهداری می‌شود و در حذف برنامه پاک نمی‌شود.

## ۳) اجرای اول

1. برنامه Trading Copier را از شورتکات دسکتاپ اجرا کنید.
2. روی هر ترمینال MT5 دکمه **Algo Trading** را فعال کنید — بدون این کار
   ارسال سفارش توسط بروکر رد می‌شود.
3. در برنامه روی **+ افزودن ترمینال** کلیک کنید:
   - دکمه **جست‌وجوی ترمینال‌های نصب‌شده** مسیرهای رایج را اسکن می‌کند؛
   - یا با **انتخاب فایل** مسیر `terminal64.exe` هر ترمینال را بدهید؛
   - نام اختصاصی بگذارید (مثلاً «مستر فارکس‌دی»، «استیو ۱»).
4. مطمئن شوید هر ترمینال به حسابش لاگین است. چند ثانیه بعد باید وضعیت اتصال
   در داشبورد **CONNECTED** شود. شماره لاگین و سرور به‌صورت خودکار خوانده و
   ثبت می‌شود (ترکیب Login + Server ملاک شناسایی است؛ اگر حساب ترمینال عوض
   شود، کپی همان ترمینال متوقف و هشدار نمایش داده می‌شود).
5. اگر ترمینالی لاگین نبود، وارد ترمینال شوید و لاگین کنید؛ برنامه به‌صورت
   خودکار متصل می‌شود. (فیلد رمز در دیالوگ افزودن ترمینال اختیاری است؛ اگر
   پر کنید فقط با DPAPI رمزنگاری و ذخیره می‌شود.)

## ۴) انتخاب مستر و استیو

1. در ردیف حساب مستر روی **تبدیل به مستر** کلیک کنید (اولین حسابی که اضافه
   می‌کنید خودکار مستر می‌شود مگر قبلاً مستر داشته باشید).
2. تغییر مستر: کپی به‌صورت ایمن متوقف می‌شود؛ بعد از انتخاب مستر جدید،
   **شروع کپی** را بزنید.
3. بقیه حساب‌ها استیو هستند. هر استیو با تیک **فعال/غیرفعال** مستقل کنترل می‌شود.
4. هیچ حسابی هم‌زمان مستر و استیو نمی‌شود.

## ۵) تنظیمات هر استیو

از دکمه **تنظیمات** در ردیف هر استیو:

- **کپی**: فعال/غیرفعال، کپی بستن بخشی، کپی سفارش‌های معلق، اتصال مجدد خودکار
- **حجم**: Same Lot / Multiplier / Fixed Lot / Balance Ratio / Equity Ratio +
  حداکثر حجم هر معامله
- **ریسک**: حداکثر تعداد پوزیشن، حداکثر اسپرد، لغزش مجاز، حداقل مارجین آزاد،
  حداقل سطح مارجین، توقف کپی در صورت افت اکوییتی
- **SL/TP**: کپی SL، کپی TP، روش انتقال (سطح مطلق یا فاصله از ورود)،
  اجازه اصلاح برای حد مجاز بروکر
- **نمادها**: فهرست نمادهای مجاز (خالی = همه) و جهت‌های مجاز (BUY/SELL)

## ۶) نگاشت نمادها

اگر نام نماد در بروکر استیو فرق دارد (مثل `EURUSD.a` یا `EURUSDm`):

- تطبیق خودکار فقط برای نام دقیقاً یکسان انجام می‌شود.
- نام‌های مشابه به‌عنوان «پیشنهاد» ذخیره می‌شوند ولی **تا تأیید شما معامله نمی‌شوند**.
- از دکمه **نگاشت نمادها** در ردیف استیو، نگاشت دستی ثبت کنید (مثلاً
  EURUSD → EURUSD.m).

## ۷) شروع کپی

1. **شروع کپی** را بزنید. اگر مستر از قبل پوزیشن باز داشته باشد سؤال می‌شود:
   - «خیر» (پیش‌فرض): فقط معاملات جدید کپی می‌شوند.
   - «بله»: پوزیشن‌های باز فعلی مستر هم به استیوها کپی می‌شوند.
2. تفاوت کنترل‌ها:
   - **PAUSE**: معاملات جدید کپی نمی‌شوند ولی مدیریت معاملات قبلی (بستن/اصلاح) ادامه دارد.
   - **STOP**: موتور کپی کامل می‌ایستد؛ معاملات موجود دست‌نخورده می‌مانند.
   - **EMERGENCY STOP**: قطع فوری ارسال دستورات + نمایش عملیات نیمه‌تمام.
   - **CLOSE COPIED POSITIONS**: فقط پوزیشن‌های متعلق به موتور کپی در استیوها
     را می‌بندد (با تأیید صریح)؛ معاملات دستی مستقل بسته **نمی‌شوند**.

## ۸) داشبورد

- نوار بالا: وضعیت مستر، وضعیت موتور کپی، تعداد حساب‌ها/متصل‌ها، تعداد
  کپی‌شده/ناموفق، میانگین و صدک ۹۵ تأخیر کپی.
- کارت مستر: بالانس، اکوییتی، مارجین‌ها، سطح مارجین، سود/زیان شناور، لوریج،
  وضعیت AutoTrading.
- جدول استیوها: همه اطلاعات + دکمه‌های عملیات هر ردیف.
- جدول پوزیشن‌های زنده: همه حساب‌ها با فیلتر حساب و ستون وضعیت کپی.
- فهرست رویدادهای زنده: زمان دقیق هر رویداد و نتیجه آن.

## ۹) تست سلامت هر ترمینال (اختیاری ولی توصیه‌شده)

در PowerShell:

```powershell
python scripts/validate_connection.py "C:\Program Files\<نام بروکر>\terminal64.exe"
```

این اسکریپت فقط می‌خواند (بدون هیچ سفارشی) و سلامت اتصال را گزارش می‌کند.

## ۱۰) حذف برنامه

از **Settings → Apps** ویندوز یا shortcut «Uninstall» در Start Menu.
دیتای کاربر در `%LOCALAPPDATA%\TradingCopier` حفظ می‌شود؛ اگر می‌خواهید
کاملاً پاک شود، آن پوشه را دستی حذف کنید.
