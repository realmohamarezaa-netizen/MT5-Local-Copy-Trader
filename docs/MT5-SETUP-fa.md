# راهنمای اتصال MT5 (فارسی)

## فعال‌سازی مجوزهای لازم در ترمینال

1. ترمینال MT5 را باز کنید → منوی **Tools → Options → Expert Advisors**.
2. تیک **Allow algorithmic trading** را فعال کنید و OK بزنید.
3. دکمه **Algo Trading** در نوار بالای ترمینال باید سبز باشد.
4. برای هر نمادی که کپی می‌شود، ترمینال باید نماد را در Market Watch داشته
   باشد (برنامه خودش با `symbol_select` نماد را انتخاب می‌کند، ولی اگر بروکر
   نماد را برای حساب فعال نکرده باشد باید از پنجره Specifications فعال شود).

## استفاده از Session موجود (بدون ذخیره رمز)

- روش پیش‌فرض برنامه: ترمینال باید از قبل لاگین باشد؛ برنامه با
  `mt5.initialize(path=...)` به همان Session وصل می‌شود و رمز نمی‌خواهد.
- اگر ترمینال لاگین نباشد، Worker «TERMINAL NOT LOGGED IN» را گزارش می‌کند و
  هر ۱ تا چند ثانیه دوباره تلاش می‌کند؛ کافی است در ترمینال لاگین کنید.
- اگر بخواهید رمز ذخیره شود (برای لاگین خودکار)، در دیالوگ افزودن ترمینال رمز
  را وارد کنید — رمز با **DPAPI ویندوز** رمزنگاری می‌شود و فقط توسط همان
  کاربر ویندوز در همان سیستم قابل بازگشایی است.

## شناسایی حساب‌ها

- ملاک شناسایی ترکیب **Login + Server + مسیر ترمینال** است، نه فقط شماره لاگین.
- اگر ترمینالی با حساب دیگری لاگین شود، کپی آن ترمینال فوراً متوقف و هشدار
  «ACCOUNT CHANGED» در داشبورد نمایش داده می‌شود.

## حساب Hedging و Netting

- نوع هر حساب به‌صورت خودکار از `margin_mode` خوانده می‌شود (0=Netting، 2=Hedging).
- ترکیب پیشنهادی: مستر و استیو هر دو Hedging (رایج‌ترین حالت ریتیل).
- Netting → Hedging: قابل کار ولی رفتار بستن بخشی متفاوت است؛ با احتیاط تست کنید.
- Hedging → Netting: معاملات خلاف جهت روی استیو همدیگر را خنثی می‌کنند؛
  توصیه نمی‌شود.

## چند ترمینال از یک نصب واحد (portable)

API پایتون متاتریدر به هر مسیر نصب فقط یک اتصال در هر پروسه می‌دهد. اگر دو
پوشه دیتا با یک `terminal64.exe` دارید، آن نصب را با کلید `/portable` کپی
کنید یا از دو مسیر نصب جداگانه استفاده کنید؛ در غیر این صورت برنامه هر دو را
یکی تشخیص می‌دهد و هشدار می‌دهد.

## فایروال / آنتی‌ویروس

برنامه فقط از Named Pipes داخلی ویندوز استفاده می‌کند و هیچ پورتی باز
نمی‌کند. تنها اتصال اینترنتی، اتصال عادی خود ترمینال‌ها به بروکر است. اگر
آنتی‌ویروس اجرای EXE جدید را محدود کرد، مسیر نصب را استثنا کنید.

## اجرای هم‌زمان چند نسخه برنامه

فقط یک نمونه از برنامه مجاز است (قفل Named Pipe). نمونه دوم با پیام
«Trading Copier is already running» بسته می‌شود.
